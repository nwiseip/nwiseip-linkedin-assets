# NwiseIP LinkedIn Company Page Assets

Brand assets for the Near & Wise IP LinkedIn company page (linkedin.com/company/nwiseip).

- `nwiseip_linkedin_logo_300.png` — square profile logo (300×300, NW mark on white). The mark itself (red `#B72C31` / navy `#002C69`) is shared with www.nwiseip.com's header logo — sampled pixel-for-pixel match.
- `nwiseip_linkedin_cover_1128x191.png` — cover banner (1128×191). Rebuilt 2026-09-22 to match www.nwiseip.com's actual CSS tokens instead of an earlier invented palette: navy gradient `#1b2a4a → #24385f` (site's `--navy`/`--navy-2`), `#c8102e` red accent (site's `--red`), Inter typeface (site's Latin font), soft rounded-card outline + shadow in place of the earlier circuit-board grid texture.

Note: the website still uses the full legal name "Near & Wise IP Law Office" throughout; LinkedIn intentionally uses the shortened "Near & Wise IP" (per 2026-09-19 decision) — this naming difference is deliberate, not an inconsistency to fix.
